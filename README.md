# 🚀 BudX – Your AI Coding Sidekick 🤖

> **"Smarter Than Your Ex. Cooler Than Your IDE."**

BudX is a **multi-modal AI-powered assistant** that’s not just smart — it's *screen-smart*. Whether you're stuck debugging, drafting emails, or building decks, BudX has your back.

Share your screen and *just ask*. BudX will analyze your code, UI, or even your bugs in real time and guide you like your dream coding buddy (minus the pizza).

## ✨ Features

### 🖥️ Screen Share Mode (⭐ Highlight Feature)
- **Live Screen Analysis**: BudX watches your screen and understands what's going on.
- **Context-Aware AI Help**: Ask questions directly related to your screen (code, errors, UI).
- **Privacy First**: Nothing is stored — all analysis is ephemeral and local.

### 🔧 Code Assistant
- **Chat Mode**: Ask for help in a code-chat interface with syntax highlighting.
- **Voice Mode**: Speak your issues — BudX listens and responds.
- **Snippet Library**: Get instant code samples with explanations.

### 📧 Email Generator
- Compose emails based on context and user profile
- Choose tone (formal, casual, funny, etc.)
- Direct send integrations (Gmail, Outlook)

### 🎯 Presentation Generator
- Generate pitch-perfect slides
- Tailor to Students, Clients, Investors, or Teams
- Format like a pro — no PowerPoint skills needed

### 🎙️ Voice Integration
- **Speech-to-Text**: Talk to BudX
- **Text-to-Speech**: BudX talks back
- Supports natural conversations with memory

## 🛠️ Tech Stack

- **Frontend**: React + TypeScript + Tailwind
- **AI Power**: Gemini (by Google)
- **Voice**: Web Speech API
- **Screen Sharing**: WebRTC + Custom AI Contextual Parser
